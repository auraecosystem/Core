# Project goals

* - Universal security engine.
* - Cross-platform (Windows, Linux,  Language-independent architecture.
* - Plugin-based design.
* - Offline-first.
* - AI-assisted security analysis.
* - Supply-chain security.
* - Enterprise-ready.
 
# Technology stack

* Core: Rust
* CLI: Rust
* API: Rust (Axum) or FastAPI if needed for AI services
* Dashboard: React + TypeScript
* Database: PostgreSQL
* Cache: Redis
* SDKs: Swift, Go, Python, JavaScript/TypeScript, Java, Kotlin, C#, Dart
* Policies: YAML or TOML
